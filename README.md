# Multi-Touch Marketing Attribution

## 📌 Project Overview

This project analyses e-commerce customer journeys to understand user behaviour, marketing touchpoints, and purchase conversion.

The objective is to identify how customers move through different stages of the purchase journey and evaluate the performance of different referral sources, devices, countries, and funnel stages.

## 📊 Dataset

The dataset used for this project is the **E-Commerce Customer Journey: Click to Conversion** dataset from Kaggle.

Dataset Source: Kaggle – E-Commerce Customer Journey: Click to Conversion

The dataset contains session-level customer journey data including:
- Session ID
- User ID
- Timestamp
- Page Type
- Device Type
- Country
- Referral Source
- Time on Page
- Items in Cart
- Purchase Status

The dataset is synthetically generated for analysing e-commerce user behaviour and conversion patterns.

## 🎯 Objectives

- Analyse customer journey and purchase behaviour
- Understand conversion funnel performance
- Analyse purchases by country
- Identify monthly purchase trends
- Compare sessions across device types
- Analyse referral sources contributing to purchases
- Understand cart-to-purchase behaviour
- Support marketing attribution and conversion analysis

## 📈 Power BI Dashboard

The interactive dashboard includes:

- Total Sessions
- Total Users
- Average Time on Page
- Total Purchases
- Purchase by Country
- Monthly Purchase Trend
- Customer Conversion Funnel
- Cart to Purchase Comparison
- Sessions by Device Type
- Purchases by Referral Source
- Country, Device Type and Referral Source filters

## 🔍 Key Dashboard Metrics

- **Total Sessions:** 12.72K
- **Total Users:** 1,872
- **Average Time on Page:** 97.43 seconds
- **Total Purchases:** 5,050

## 💡 Key Insights

- France recorded the highest purchases among the countries shown.
- Purchase activity varies across months, with March showing a noticeable peak.
- Device-wise sessions are relatively balanced across Mobile, Desktop and Tablet.
- Google generated the highest purchases among the referral sources shown.
- The conversion funnel shows a progressive drop-off from homepage visits to completed purchases.


## 📌 Conclusion

This project provides an overview of the e-commerce customer journey and helps identify important patterns in marketing channels, customer behaviour, and conversion performance.

The analysis can help businesses understand customer touchpoints and make better data-driven marketing decisions.
